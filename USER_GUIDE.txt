🔐 Активация Pro / Enterprise версии

Вы можете активировать платные функции двумя способами:

1. Через интерфейс приложения:
   - Откройте меню "Настройки" (⚙️)
   - Введите ключ в поле "Premium ключ" или "Enterprise ключ"
   - Нажмите "OK"

2. Через файлы (для автоматизации):
   - Откройте папку config/ (рядом с приложением)
   - Поместите файл с ключом:
     * premium_key.txt — для Premium
     * enterprise_key.txt — для Enterprise
     * api_key.txt — для облачного режима
   - Перезапустите приложение

📂 Где найти папку config?
   Она находится в той же папке, где лежит исполняемый файл приложения.

💡 Как получить ключ?
   Ключи выдаются при покупке подписки на сайте или по запросу.

🆓 Бесплатный режим
   Без ключа вы можете использовать базовые функции (5 сканирований в месяц).

☁️ Облачный режим
   Для работы в облачном режиме требуется запущенный бэкенд.
   Запустите бэкенд командой: uvicorn main:app --host 0.0.0.0 --port 8000

📊 Сканирование
   - Укажите URL OpenAPI-спецификации или путь к локальному файлу.
   - Выберите режим: Локальный (бесплатно) или Облачный (требуется ключ).
   - Нажмите "Начать сканирование".

📄 Отчёты
   Результаты сканирования сохраняются в виде HTML/PDF/JSON.
   Используйте меню "Файл → Экспорт отчёта".

❓ Помощь
   В меню "Помощь" есть справка по ошибкам и база знаний правил.
